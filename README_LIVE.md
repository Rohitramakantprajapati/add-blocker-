## ❓ FAQ

**Q: I don't see my website after enabling GitHub Pages**
A: Wait 2-3 minutes. Sometimes it takes time. Then refresh your browser and clear cache.

**Q: The website shows error**
A: Make sure you selected `/docs` folder in GitHub Pages settings, not root.

**Q: How do I get the GitHub Pages URL?**
A: It's automatically: `https://YOUR_USERNAME.github.io/REPO_NAME/`
Your case: `https://rohitramakantprajapati.github.io/add-blocker-/`

**Q: Can I use a custom domain?**
A: Yes! After GitHub Pages is enabled, go to Settings → Pages → Custom domain (follow the DNS setup).

**Q: What if I don't want GitHub Pages?**
A: You can still share the GitHub repo link directly. But GitHub Pages makes it more professional.
